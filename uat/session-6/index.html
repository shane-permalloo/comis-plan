Who does what

Four roles, prepared data

The roles

Cooperative Society (Applicant): makes the amendment, follows it up, checks the history and the Dashboard.

Registrar Officer: reviews amendments, searches, views history and cooperatives.

Registrar Supervisor: decides amendments and also checks the Dashboard.

IT Administrator (on call): changes the announcements and quick links.

MNS has prepared

By-Laws amendments in different statuses.

A cooperative with an approved amendment.

A rejected assessment.

An Active cooperative from the fast track, for the Dashboard checks.

Officer reviews the amendment

Done by the Registrar Officer

StepWhat to doWhat you should see
1Search for status Pending Review.The application is listed.
2Click the Edit icon in the Action column.The Review By Laws Amendment screen opens.
3Click Action Required.A pop-up offers Recommend for Approval, Request for Amendment or Reject, with a comment box.
4Choose an action, enter a comment and click Confirm.Status becomes Awaiting Supervisor Review, Amendment Requested (RO) or Rejected.

Done when: each officer has used a different action on a different application.
