How we test

This is a check, not an exam

1. Follow the steps

Do each step in order, as written on the screen.

2. Compare

Check what you see against “What you should see”.

3. Record the result

Tick the box if it matches. If not, write what you saw, on which screen and for which user.

4. Do not fix

Nothing is fixed during UAT. Problems are classified at the virtual meeting on Tuesday 3 November.

Create a user on the public portal admin

What you do

  1. Sign in to the public portal admin.
  2. Open the users section and add a new user.
  3. Enter a name, an email address and a role. Save.
  4. Sign in as the new user in a private window.

What you should see

The new user can sign in and sees only what the role allows.

Publish content on the public portal

What you do

  1. Create an information page and publish it.
  2. Add a resource, for example a document, and publish it.
  3. Open the public website in a private window, signed out.
  4. Find the page and the resource. Download the resource.
  5. Remove both, then check they are gone from the website.

What you should see

The page and the resource appear on the website once published, and the download works.

After removal, neither can be found.

When something does not match

How to record a problem

Write down

  • The step you were on and the screen you were on.
  • The user you were signed in as.
  • What you expected and what you saw.
  • The time, and a screenshot if you can.

Four levels

Critical: blocks a core process, no workaround

High: a major function fails

Medium: a minor error or easy workaround

Low: cosmetic or wording

The team classifies every problem at the meeting on Tuesday 3 November. Nothing is fixed before then.
